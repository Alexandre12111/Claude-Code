YouCraft — brand kit (v1, October 2026)
=======================================

Slogan: "Got an idea? Craft it."
Supporting line: "From business idea to working solution."

Start with YouCraft_brand-guidelines.pdf: logo rules, colours, type, tone and motion.

01-logos       Logo in 4 versions (horizontal = primary, stacked, symbol, wordmark),
               each in colour-on-dark, colour-on-light, black and white.
               svg/ = vector, text outlined (no font needed) · png/ = transparent, 3 sizes.
02-icons       App icon (ink / stone) SVG + PNG, favicon.ico and favicon PNGs.
03-animations  Intro animation GIFs: 960x540 and 1080x1080, dark and light.
04-colors      Palette sheet (PNG), CSS + JSON tokens, Adobe swatches (.ase).
               CMYK values in the JSON are approximations: proof before printing.
05-typography  Plus Jakarta Sans (headlines) and DM Sans (text): TTF to install,
               web/ WOFF2 for developers. Both under the SIL Open Font License (OFL files).
06-social      Share card 1200x630, square post 1080x1080, LinkedIn banner 1584x396.

Note: working version — the YouCraft name is pending final validation.
