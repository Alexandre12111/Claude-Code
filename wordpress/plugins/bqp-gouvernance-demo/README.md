# BQP Gouvernance : démo

Membres fictifs pour tester le design de la gouvernance. À installer le temps des tests, puis à supprimer.

Nécessite **BQP Gouvernance 1.3 ou plus**.

## Installation

1. Ouvrir `bqp-gouvernance-demo-code-snippets.txt`
2. Copier tout le contenu dans un **nouveau** snippet (ne pas remplacer celui de la gouvernance)
3. Régler sur **Run everywhere**, enregistrer et activer
4. Aller dans **Gouvernance › Membres de démo** et cliquer sur **Créer les membres de démo**

## Ce qui est créé

- **11 membres fictifs** : 5 au Bureau (présidente, vice-président, secrétaire générale, trésorier, déléguée aux lauréats) et 7 au Conseil scientifique, dont le vice-président, présent dans les deux instances
- un **portrait** généré pour chacun (silhouette sur fond coloré), sauf le trésorier, pour voir les initiales
- une **fiche détaillée** : profession, rôle dans l'association, présentation, parcours, lien, et un **CV en PDF** pour trois membres
- un membre sans fiche (Élodie Fontaine), qui reste une carte simple

Les noms, textes et liens sont inventés. Les liens mènent vers `example.org`, un domaine réservé aux exemples. Les membres n'ont pas de page publique : rien n'est indexé par Google.

## Supprimer

**Gouvernance › Membres de démo › Tout supprimer** retire les membres de démo, leurs portraits et leurs CV, et rien d'autre : seuls les contenus marqués « démo » sont concernés. Supprimer ensuite le snippet.
