# Gérer le site DualTech avec Claude

## 1. Installer l'assistant (une seule fois, 2 minutes)

1. Ouvrez **claude.ai** et connectez‑vous.
2. Cliquez sur votre nom en bas à gauche → **Paramètres** → **Fonctionnalités**.
3. Vérifiez que **Exécution de code et création de fichiers** est activé.
4. Dans **Skills**, cliquez sur **Importer un skill** et choisissez le fichier **dualtech-site.zip** (sans le décompresser).
5. Vérifiez que le skill **dualtech-site** est activé.

> Vous ne voyez pas « Skills » ? Créez un **Projet** nommé « Site DualTech », puis dans **Instructions du projet**, collez le contenu du fichier `SKILL.md`, et ajoutez `site.md` dans les **Connaissances** du projet. Posez ensuite vos questions dans ce projet.

## 2. Faire une modification

1. Ouvrez une nouvelle conversation dans Claude.
2. Écrivez ce que vous voulez, simplement. Par exemple :
   * « Ajoute un intervenant au site DualTech : Marie Durand, directrice innovation chez Safran. »
   * « Je veux changer l'heure de la table ronde de 14h15. »
   * « Où je vois les messages du formulaire de contact ? »
   * « Écris‑moi une nouvelle question pour la FAQ de l'accueil sur le parking. »
   * « Propose un meilleur titre Google pour la page Programme. »
3. Claude vous donne les étapes, une par une, avec les menus où cliquer. Pour un texte de page, il vous donne le texte ou le code à copier‑coller.
4. En cas de doute, **envoyez‑lui une capture d'écran** de ce que vous voyez : il vous dira où cliquer.

## 3. Les 3 règles d'or

1. **Partenaires, intervenants, programme et demandes** : toujours dans le menu **DualTech** à gauche de l'administration (https://dualtech-event.eu/wp-admin), jamais dans le code des pages.
2. Avant de modifier le code d'une page, **copiez l'ancien contenu** dans un fichier texte.
3. Ne cliquez jamais sur **Apparence → Installation DualTech** : cela remettrait toutes les pages à leur version d'origine.

Un problème que Claude ne règle pas (page blanche, formulaire en panne, changement de design) : contactez Alexandre (Aurea Media).
