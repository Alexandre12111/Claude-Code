# Vidéo motion design IP Box, Leyton (V1, 90 s)

Vidéo explicative du régime IP Box, sur le même modèle que la vidéo CIR (V10) : main 3D au feutre Leyton, écriture lettre par lettre, voix off synchronisée, sous-titres karaoké, design system issu du skill `ui-ux-pro-max` (voir [`design-system/MASTER.md`](design-system/MASTER.md)).

Toutes les informations viennent uniquement du livre blanc « France, Livre Blanc IP Box 2026 ».
