# Vidéo motion design CIR, Leyton (V5)

Vidéo explicative de 82 secondes sur le Crédit d'Impôt Recherche, charte Leyton.

## Nouveautés par rapport à la V4

* Pouce remodélisé : flexion anatomique, posé en face de l'index sur le feutre, ongle du bon côté et adouci
* Main plus fluide et plus lente : tracés à vitesse régulière, une seule main qui enchaîne les traits sans chevauchement, déplacements en courbes continues, trajectoire lissée image par image (secousses fortes divisées par 20, aucun arrêt)
* Petits détails (rayons, colonnes, bulles) tracés automatiquement pendant que la main dessine les éléments principaux
* Nouvelle formulation, plus naturelle : « C'est le crédit d'impôt recherche, qu'on appelle le cire »
