# Vidéo motion design CIR, Leyton (V7)

Vidéo explicative de 67 secondes sur le Crédit d'Impôt Recherche, charte Leyton.

## Nouveautés par rapport à la V6

* Transitions variées et brandées : iris en anneau Leyton avec le logo, balayage de pinceau orange, panoramique rapide avec bascule, traînées de vitesse et flash
* Feutre précis : la pointe suit exactement le trait ; vitesse qui ralentit dans les courbes et les angles ; le feutre se lève entre deux morceaux d'un tracé
* Main naturelle : le bras pivote depuis l'épaule, légère profondeur, micro tremblement, écriture rythmée lettre par lettre, approches souples
* Immersion : caméra flottante façon épaule, coups de zoom sur les moments clés, particules de profondeur au premier plan, reflet de lumière à chaque tableau, sons dédiés pour chaque transition
