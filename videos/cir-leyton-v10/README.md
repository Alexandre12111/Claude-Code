# Vidéo motion design CIR, Leyton (V10, 90 s)

Version longue de la V9 : même design (skill `ui-ux-pro-max`, voir [`design-system/MASTER.md`](design-system/MASTER.md)), même main 3D et même voix, avec plus de détails tirés du Guide CIR 2026.

## Ajouts par rapport à la V9

* Nouveau chapitre « Les travaux éligibles » : recherche fondamentale, recherche appliquée, développement expérimental (référence : Manuel de Frascati, OCDE)
* Chiffres clés : les quatre secteurs (industrie, commerce, artisanat, agriculture) sont cités et apparaissent chacun sur leur mot
* Utilisation : le remboursement immédiat concerne aussi les jeunes entreprises innovantes et les entreprises nouvelles
* Justification : contrôle possible jusqu'à 3 ans après, et le rescrit pour valider ses projets en amont
* 9 chapitres (repère 01/09), dézoom final sur les 10 tableaux
