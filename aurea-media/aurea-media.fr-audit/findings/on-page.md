# SEO on-page

**Score : 90/100**

- Titres : toutes les pages entre 30 et 62 caractères, aucun doublon.
- Descriptions : toutes entre 110 et 165 caractères, aucun doublon (sauf la page vide /en/accueil-english/ et les rubriques).
- Un seul H1 sur chaque page.
- Maillage interne : chaque page reçoit au moins 3 liens internes ; la seule page orpheline est /en/accueil-english/.
- Rubriques du blog sans description : passées en noindex (3.1.2).
