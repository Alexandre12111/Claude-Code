# Kit réseaux sociaux Aurea Media

- `export/` : les visuels prêts à publier (photo de profil, couvertures, stories à la une, 3 premières publications).
- `TEXTES-PROFILS.md` : noms, bios, descriptions, coordonnées et légendes, prêts à copier.
- `sources/` : `kit.html` (maquettes), `exporter-kit.js` (régénère tous les PNG : `node sources/exporter-kit.js`), logo monogramme vectoriel (SVG clair et encre), polices, icônes.
